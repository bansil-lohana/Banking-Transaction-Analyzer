# Banking Transaction Analyzer

A Java-based Data Structures and Algorithms (DSA) project for analyzing banking transactions.

## Features

- Search transactions using Linear Search
- Search transactions using Binary Search
- Sort transactions by amount using Merge Sort
- View failed transactions
- View the last 5 transactions using a Circular Queue
- View all transactions

## DSA Concepts Used

- Arrays
- Linear Search
- Binary Search
- Merge Sort
- Circular Queue

## Technologies

- Java
- Object-Oriented Programming (OOP)
- Data Structures and Algorithms

## How It Works

The program stores banking transactions containing:

- Transaction ID
- Amount
- Transaction Type
- Transaction Status

Users can select different operations from a console-based menu to search, sort, filter, and view transactions.
